# Üçüncü Taraf Bildirimleri

Bu repository'nin UI ve kurulum scriptleri MIT lisansı ile sunulur. Kurulum sırasında kullanılan aşağıdaki üçüncü taraf bileşenler kendi lisanslarına tabidir.

## OpenBMB VoxCPM / VoxCPM2

- https://github.com/OpenBMB/VoxCPM
- https://huggingface.co/openbmb/VoxCPM2
- Upstream tarafından belirtilen lisans: Apache-2.0

VoxCPM2 model ağırlıkları bu repository içinde dağıtılmaz; `install.bat` sırasında Hugging Face'ten indirilir.

## PyTorch / torchaudio / torchvision

- https://pytorch.org/
- Kendi açık kaynak lisanslarına tabidir.

## TorchCodec

- https://github.com/meta-pytorch/torchcodec
- Kendi açık kaynak lisansına tabidir.

## FFmpeg

- https://ffmpeg.org/
- Windows build kaynağı: https://www.gyan.dev/ffmpeg/builds/
- Binary repository'de dağıtılmaz; installer tarafından indirilir.
- FFmpeg ve kullanılan build'in lisans şartları ayrıca geçerlidir.

## Python

- https://www.python.org/
- Python Software Foundation lisansına tabidir.

## Hugging Face

- https://huggingface.co/
- VoxCPM2 model dosyalarının indirilmesinde kullanılır.

Bu dosya hukuki danışmanlık değildir. Dağıtım veya ticari kullanım öncesi bütün upstream lisansların güncel hâllerini inceleyin.
